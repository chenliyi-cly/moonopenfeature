# MoonOpenFeature

Provider-neutral MoonBit SDK core targeting the OpenFeature v0.9.0 application contract. Providers own feature decisions; this package does not implement a rule engine or rollout planner. The implementation is under active development; no conformance or publication claim is made by this initial checkpoint.

See docs/competition/duplicate-check.md for scoped research and fixed upstream references. API, examples and verification instructions are added with their implementations.
